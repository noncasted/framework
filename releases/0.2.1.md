## Шаги

Поиск из корня игры.

### 1. Ссылка на скилл `media-cleanup`

Кого касается: все игры. `INDEX.md` велит закончившей задачу сессии вызвать этот скилл, а `workflow-complete` теперь только вызывает его. Без ссылки вызывать нечего.

Поиск: `git ls-files .claude/skills/media-cleanup`. Пусто: ссылки нет, она нужна. На момент релиза её нет ни в одной игре.

Сделать: `ln -s ../../tools/framework/.claude/skills/media-cleanup .claude/skills/media-cleanup`. Сессия, закончив задачу, вызывает его сама: удаляет лишние файлы и
переносит свою работу в `docs/media/research/complete`.

## Проверить поведение

Правило уборки `docs/media` переехало из `INDEX.md` и `workflow-complete` в `media-cleanup`. Новое в нём: трогает только работу своей сессии, чужие и незаконченные
папки оставляет, неотслеживаемый файл удаляет только если он из списка лишнего.

## Без действий

- `update-framework`: `$TARGET` в кавычках, команды работают в zsh. Файл скилла в игре читает инструкцию из последнего тега, правка доходит сама.
- `release-framework`: пуш сразу и атомарно, вместе с тегом.
