## Steps

Search from the root of the game.

### 1. The link to the skill `media-cleanup`

Who: every game. `INDEX.md` tells a session that finished its task to call this skill, and `workflow-complete` now only calls it. Without the link there is nothing to call.

Search: `git ls-files .claude/skills/media-cleanup`. Empty: no link, it is needed. At the time of the release no game has it.

Do: `ln -s ../../tools/framework/.claude/skills/media-cleanup .claude/skills/media-cleanup`. A session that finished its task calls it itself: it deletes the extra files and
moves its work to `docs/media/research/complete`.

## Check the behaviour

The rule of cleaning `docs/media` moved from `INDEX.md` and `workflow-complete` to `media-cleanup`. New in it: it touches only the work of its own session, leaves the folders of
others and the unfinished ones, deletes an untracked file only if it is on the list of extras.
