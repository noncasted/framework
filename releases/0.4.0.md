# 0.4.0

53 коммита (`v0.3.0..HEAD`). Телеметрия клиентов расширена: кадр по фазам, GPU, WebGL, страница, незакрытая прошлая сессия, предупреждения, загрузки ассетов, страница до Unity в трейсе запуска; протокол телеметрии изменился. ### 1. Телеметрия: протокол, `AddCollector`, подделки в тестах

Кому: клиент и бэкенд игр с телеметрией, `BREAKING` (протокол). У `SharedClientTelemetry.Mark` поля `Detail`, `DurationMs`, у `StartupSpan` поля `File`, `TransferBytes`, `Cached`, у `SessionStart` поле `Previous` (`PreviousSession` с `SampleNames`, `Samples`), уровень `ErrorLevel.Warning`. Старый сервер не прочтёт `SessionStart` нового клиента.

Поиск: `git grep -nE 'class \w+[^{]*[:,] *(IClientTelemetry|ITelemetryPage|ITelemetryGlErrors|ITelemetryStartupSource)\b|new (TelemetrySessionTrace|TelemetryPreviousSession|TelemetryStartupReport)\(|TelemetryStartupTraces\.Build\(|ErrorLevel\.(Error|Exception)' -- '*.cs'`

- Подделка `IClientTelemetry`: `public void AddCollector(IReadOnlyLifetime lifetime, ITelemetryCollector collector) { }`. Коллекторы
  забега, которым раньше нужен был мост в скоуп meta, регистрировать так: `telemetry.AddCollector(runLifetime, collector)`.
- Подделка `ITelemetryPage`: `public IEventSource<TelemetryPageEvent> Lifecycle => _lifecycle;` и
  `public IEventSource<TelemetryCanvasSize> Resized => _resized;` (оба `EventSource<...>`).
- Подделка `ITelemetryGlErrors`: `public double LastTakeMs => 0d;`.
- Свой `ITelemetryStartupSource`: добавить `double SinceStartMs()` (время от начала трейса). `TelemetryStartupReport` принимает
  `TelemetryStartupPage`, `TelemetryStartupTraces.Build` - `TelemetryStartupPrefix` (`TelemetryStartupPrefix.None` вне веба).
- `TelemetrySessionTrace` принимает третьим аргументом `TelemetryNameTable`, `TelemetryPreviousSession` - ещё `sampleNames` и `samples`.
- Свой `switch` по `SharedClientTelemetry.ErrorLevel` дополнить `Warning`.
- Приходят сами с `AddStandardTelemetryCollectors` и `AddSocketClientTelemetry`: фазы кадра, `frame.spike*`, `gc.allocated`,
  `frame.gpu.query`, `render.*`, `settings.*`, `web.raf.dt.*`, `web.gl.*` (ошибки, вызовы, шейдеры, буферы, текстуры), `page.*`,
  `audio.context.*`, `memory.texture_count`, `net.meta.*`, предупреждения лога, след незакрытой сессии; на странице сессии консоли
  блок прошлой сессии. По желанию: `new ClientTelemetryOptions(slowShaderMs: 50d, slowLoadSeconds: 5f, devProfilerMarkers: new[] { ... })`
  (`dev.*` только в development-сборке). Страница с `?glcheck` проверяет каждый вызов GL.


### 2. Телеметрия: страница до Unity в трейсе запуска, загрузки ассетов

Кому: игры с телеметрией (WebGL-шаблоны) и игры, которые грузят Addressables в обход групп каталогов и сцен скоупов.

Поиск: `git grep -nE 'createUnityInstance|loaderUrl|telegram-web-app.js|WebApp.ready|startupTrace' -- 'client/Assets/WebGLTemplates/*/index.html' 'client/Assets/WebGLTemplates/*/TemplateData/*.js'`;
`git grep -nE 'Addressables\.(Load|Instantiate)' -- 'client/Assets/*.cs'`

- Шаблон ничего не подключает сам: сборка WebGL кладёт `window.startupTrace` первым скриптом в `<head>` собранного `index.html`
  (`TelemetryStartupTraceInjection`, у страницы без `<head>` сборка падает). Шаблон только ставит спаны, имена без цифр:
  - вокруг блокирующего SDK платформы в `<head>`: `<script>startupTrace.begin('Telegram SDK')</script>` перед `telegram-web-app.js`,
    `<script>startupTrace.end('Telegram SDK')</script>` после;
  - колесо загрузки: `startupTrace.begin('Loading wheel')` при показе, `startupTrace.end('Loading wheel')` при скрытии;
  - загрузчик: `startupTrace.begin('Unity loader')` перед `document.body.appendChild(script)`, `startupTrace.end('Unity loader')` в `script.onload`;
  - инстанс: `startupTrace.begin('Unity instance')` перед `createUnityInstance`, в колбэке прогресса по разу `startupTrace.mark('Progress quarter')`,
    `'Progress half'`, `'Progress three quarters'`, `'Progress done'`, в `.then` `startupTrace.end('Unity instance')`, в `.catch`
    `startupTrace.mark('Unity instance failed')`;
  - Telegram: `startupTrace.mark('Telegram ready')` рядом с `Telegram.WebApp.ready()`.
  Пример: `client/Assets/WebGLTemplates/Default/index.html` pixel-swarm. Игре без телеметрии шаблон трогать не нужно.
- Загрузки групп каталогов и сцен скоупов отмечаются сами (`AssetLoads` ядра). Загрузку Addressables в обход них обернуть:
  `var load = AssetLoads.Begin("Group: <имя>");` ... `load.Finish();`, при исключении `load.Fail(exception)`. Найдено:
  peace-data-reborn `LocationBuilder.cs`, storytale-workshop `NodesRegistry.cs`, `HardcodedBookPlayer.cs` (редакторный
  `NodesRegistryGenerator.cs` не нужно). Без обёртки ничего не ломается: загрузка просто не видна в телеметрии.


### 3. Сеть: отправка без аллокаций

Кому: клиент, игры со своими реализациями `IWebSocket`, `IConnectionWriter`, `INetworkProperty` (обычно подделки в тестах), `BREAKING` (API; формат на проводе тот же).

Поиск: `git grep -nE 'class \w+[^{]*[:,] *(IWebSocket|IConnectionWriter|INetworkProperty)\b' -- 'client/Assets/*.cs'`

- `IWebSocket.Send(byte[])` стал `Send(ArraySegment<byte> bytes)`: байты снова принадлежат вызывающему, когда задача завершилась;
  сокет, который держит их дольше, копирует (`bytes.ToArray()`). Вызов с `byte[]` компилируется как есть.
- `IConnectionWriter` получил `void WriteOneWay(ReadOnlySpan<byte> message)` (байты `IMessageFromClient`, копируются сразу); подделке
  достаточно `=> throw new NotSupportedException()`.
- `INetworkProperty` получил `void Collect(IBufferWriter<byte> buffer)`. Для реализации, как `NetworkProperty`:
  `public void Collect(IBufferWriter<byte> buffer) { _isDirty = false; MemoryPackSerializer.Serialize(buffer, Value); }`
  (`using System.Buffers;`). peace-data-reborn: `DamageNetworkProperty`.
- Сообщение сериализуется в момент `WriteOneWay` / `WriteRequest` / `WriteResponse`, а не в цикле отправки: объект сообщения можно
  переиспользовать сразу после вызова.
- `ViewableDictionary.Values` теперь struct-коллекция (`foreach` без аллокаций); через `IReadOnlyDictionary` по-прежнему `IEnumerable`.
  Раньше было `IEnumerable<TView>`, код компилируется как есть (присвоение в `IEnumerable<T>` упаковывает).


### 4. UI: экранные канвасы фреймворка (`IScreenCanvasCamera`)

Поиск: `git grep -nE 'AddNetwork\(|AddClientOutdatedNotice\(|AddScreenCanvas|new NetworkLatencyMonitor\(|new ClientOutdatedNotice\(' -- 'client/Assets/*.cs'`

    её клип-плоскостями>)`, в pixel-swarm `builder.AddScreenCanvasCamera(UICamera.Get, UICamera.Layer, UICamera.PlaneDistance)`;
    камера спрашивается при каждом показе, канвас и всё под ним ставятся на этот слой;

### 11. Хостинг: лидер лобби в `ILobbyMatches.Create`

Кому: бэкенд игр с лобби (своя реализация `ILobbyMatches`, подделки в тестах), `BREAKING`.

## Проверить поведение

- `LifetimedValue`: время жизни значения создаётся при первом обращении, `Notify` без слушателей ничего не выделяет; после `Dispose`
  `ValueLifetime` остаётся завершённым. Код, который сравнивал `ValueLifetime` по ссылке до и после `Notify`, проверить.
- `SafeAreaPadding` пересчитывается только при изменении безопасной зоны или размера корня, а не каждый кадр.
- `NetworkProperty.Set` сравнивает через `EqualityComparer<T>.Default`: у типа значения со своим `Equals(T)` без `Equals(object)`
  результат может отличаться.
