# 0.13.1

1 коммит (`v0.13.0..d85670ca`): каталог спрайтов режет клипы из полосы PNG. PNG с видом Multiple Animations описывает в userData
именованные клипы (диапазоны и списки кадров, кадры соседней полосы той же папки), генератор нарезает их во вложенные объекты группы
без запекания, как теги aseprite. Строки клипов редактируются в инспекторе каталога. `EditorCatalogues.Bind` привязывает
сгенерированные каталоги к ассетам проекта вне Play mode: для инструментов редактора и EditMode-тестов. Игре делать ничего не нужно.

## Состояние игр

## Проверить поведение

- PNG с `kind: MultipleAnimations` в userData раньше генерировался как обычная полоса (вид работал только у aseprite). Теперь без
  `clips` генерация падает (`... is marked as Multiple Animations and has no clips`), как и при сломанном клипе: нет имени, имя
  повторяется, `time` <= 0, кадр вне полосы. Поиск: `git grep -l MultipleAnimations -- '*.png.meta'`. В найденных файлах без `clips`
  поменять вид на Animation или разметить клипы.

## Без действий

- `SpriteCatalogClip`, `SpriteClipFrames`, `SpriteStripClips`, `SpriteStripClipsGUI` (`Internal.Editor`) - клипы полосы PNG в каталоге спрайтов.
- `EditorCatalogues.Bind(lifetime, mainBundle)` (`Internal.Editor`) - каталоги в edit mode; в Play mode бросает.
