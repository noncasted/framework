## Шаги

### 1. Бэкенд: `AcceptStartup` принимает backend trace id сокета (BREAKING)

Кого касается: бэкенд игр с телеметрией клиентов (`AddClientTelemetry`), которые зовут `AcceptStartup` в командах мета-сокета. Запись
startup trace хранит id трейса авторизации сокета в OTLP-бэкенде (`BackendTraceId`, консоль: `Backend trace`, чтение: `backendTraceId`), по
нему трейс бэкенда ищется в Aspire dashboard -> Traces.
Поиск: `git grep -n "AcceptStartup(" -- backend`
Сделать: `telemetry.Of(session.Lifetime).AcceptStartup(request)` -> `.AcceptStartup(request, backendTrace)`, где `backendTrace` -
`ActivityTraceId` span-а авторизации этого сокета (`System.Diagnostics`); у игры нет такого span-а - передать `default` (запись без id).
Тесты игры, которые зовут `AcceptStartup`, получают второй аргумент `default`. HTTP-приём (`MapClientTelemetryHttpIntake`) передаёт
`default` сам.

### 2. Консоль: backend-трейс startup клиента из Aspire dashboard (необязательно)

Кого касается: консоль игры с телеметрией клиентов (`AddClientTelemetryReader`), которая хочет видеть трейс бэкенда на странице startup.
Без шага ничего не меняется: страница показывает только id (`Backend trace`).
Поиск: `git grep -n "AddClientTelemetryReader" -- backend`
Сделать: в консоли `builder.AddConsoleBackendTraces(builder.Configuration.GetSection("AspireDashboard"))` (секция `Url`, `ApiKey`; пустое
значение бросает) или `builder.AddConsoleBackendTraces(new ConsoleBackendTraceOptions { BaseUrl, ApiKey, Timeout })` (namespace
`Console.Infrastructure.BackendTraces`). Дашборду - `DASHBOARD__API__AUTHMODE=ApiKey` и `DASHBOARD__API__PRIMARYAPIKEY=<ключ>` (тот же ключ
консоли); `Url` - адрес фронтенда дашборда (`GET <Url>/api/telemetry/traces/{id}`, header `x-api-key`). Дашборд хранит телеметрию в памяти:
после его рестарта трейс - "no longer in the dashboard".

## Без действий

- `GameProfiler.Background(name)`: корень трейса для ветки, которую никто не ждёт (не стадия, не на стеке); спаны загрузок контента
  называются `Content: <ассет>` / `Content: scene <сцена>`.
- `WebContentFetch` и `WebContentBundleStore` компилируются только под `UNITY_WEBGL && !UNITY_EDITOR`: IL2CPP-сборки вне WebGL
  (StandaloneLinux64, Android) больше не падают на линковке `__Internal`. Игры ссылаются на них только в комментариях.
- Генератор `ContentRoot` находит группы каталогов по главному типу ассета, а не поиском `t:`.
- Спрайтовая анимация после длинного delta останавливается на последнем кадре.
- Скилл `client-telemetry`: `report.py` печатает `backend_trace=`; ссылка на скилл не меняется.
- `client/measurements`: архив замеров загрузки контента на 7000.0.0a10.
