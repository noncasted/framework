## Steps

### 1. Backend: `AcceptStartup` takes the backend trace id of the socket (BREAKING)

Who: the backend of games with client telemetry (`AddClientTelemetry`) that call `AcceptStartup` in the commands of the meta socket. The startup
trace record keeps the id of the trace of the socket authorization in the OTLP backend (`BackendTraceId`, console: `Backend trace`, read API: `backendTraceId`), by
which the backend trace is found in Aspire dashboard -> Traces.
Search: `git grep -n "AcceptStartup(" -- backend`
Do: `telemetry.Of(session.Lifetime).AcceptStartup(request)` -> `.AcceptStartup(request, backendTrace)`, where `backendTrace` is the
`ActivityTraceId` of the authorization span of this socket (`System.Diagnostics`); a game without such a span passes `default` (a record without the id).
Tests of the game that call `AcceptStartup` get the second argument `default`. The HTTP intake (`MapClientTelemetryHttpIntake`) passes
`default` itself.

### 2. Console: the backend trace of a client startup from the Aspire dashboard (optional)

Who: the console of a game with client telemetry (`AddClientTelemetryReader`) that wants to see the backend trace on the startup page.
Without the step nothing changes: the page shows only the id (`Backend trace`).
Search: `git grep -n "AddClientTelemetryReader" -- backend`
Do: in the console `builder.AddConsoleBackendTraces(builder.Configuration.GetSection("AspireDashboard"))` (section `Url`, `ApiKey`; an empty
value throws) or `builder.AddConsoleBackendTraces(new ConsoleBackendTraceOptions { BaseUrl, ApiKey, Timeout })` (namespace
`Console.Infrastructure.BackendTraces`). For the dashboard: `DASHBOARD__API__AUTHMODE=ApiKey` and `DASHBOARD__API__PRIMARYAPIKEY=<key>` (the same key as the
console's); `Url` is the address of the dashboard frontend (`GET <Url>/api/telemetry/traces/{id}`, header `x-api-key`). The dashboard keeps the telemetry in memory:
after its restart the trace is "no longer in the dashboard".

- Skill `client-telemetry`: `report.py` prints `backend_trace=`; the link to the skill does not change.
