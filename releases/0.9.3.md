# 0.9.3

89 commits (`v0.9.2..6d1d7a25`): the fixes of the backend and client audits of 2026-11-16 (`docs/audits/2026-11-16_backend.md`,
`docs/audits/2026-11-16_client.md`), both branches merged on top of 0.9.2. Backend: a dirty write of a state outside an open transaction is now
an error, the shared values of a host are safe for the console (`SharedViewableProperty<T>`), the lobbies of a fallen server leave the list, a host follows
only a newer deploy. Client: the catalogue generators fail on a broken input, the P2P network (the signaling of a returning guest, the silence of
the control connection), the telemetry and match-metrics, dead code removed. By the rule of the versions this is `MINOR` (the games have steps), the number
`0.9.3` was chosen at the request of the user.

## Steps

### 1. Backend: the fixes of the audit of 2026-11-16 (BREAKING)

Who: the backend of every game. Report: `docs/audits/2026-11-16_backend.md`. Search from the root of the game, no matches: the item is skipped.

- `DbLookup` removed, the side effects tables are now `SideEffectTables` (namespace `Common`): `git grep -n "DbLookup" -- backend` -
  `DbLookup.SE_Queue / SE_Processing / SE_Retry / SE_DeadLetter` -> `SideEffectTables.Queue / Processing / RetryQueue / DeadLetter`
  (mines-leader, pixel-swarm, peace-data-reborn, storytale-workshop, gamejam-autobattler; post-radio has its own `DbLookup`).
- `IClusterParticipantContext.IsInitialized / IsMessagingStarted / CurrentStageIndex` are `ISharedViewableProperty<T>`:
  `git grep -nE "(IsInitialized|IsMessagingStarted|CurrentStageIndex)\.Returns" -- backend` - in the context substitutes
  `new SharedViewableProperty<bool>(true)`, a field the substitute returns is also `SharedViewableProperty<T>` (mines-leader
  `MatchmakingTests`). `IsOrleansStarted` of the other observers did not change.
- `ISessionsCollection` / `SessionsCollection` of the framework (`backend/Hosting`) moved to `Game.Hosting.Collection`:
  `git grep -ln "SessionsCollection" -- backend` - add `using Game.Hosting.Collection;` (pixel-swarm, storytale-workshop). A game with
  its own `SessionsCollection` (mines-leader, peace-data-reborn) changes nothing.
- `LobbyListing.IsJoinable` removed (old rows are read), `ILobbyCodeLeases.IsMatchJoinable` -> `IsPassedToMatch`:
  `git grep -n "IsJoinable" -- backend` - remove the assignment (pixel-swarm `Tools/Tests/Meta/OpenLobbiesSubscriptionsTests.cs`).
- `TraceExtensions.Start(name)` removed: `git grep -nE '\.Start\("' -- backend` - `source.StartActivity("X")` (returns `Activity?`;
  storytale-workshop, `MetaGateway`).
- `RuntimeChannelObserver.ResetLastSeen(long)` removed: `git grep -n "ResetLastSeen(" -- backend` - remove the copy of the test
  `Observer_ResetLastSeen_AllowsLowerSequenceAfterGap` (mines-leader, peace-data-reborn).
- `IDeploymentState<T>` is now `SharedViewableProperty<T>`: an own class on `ViewableProperty<T>` that implements `IDeploymentState<T>`
  derives from `SharedViewableProperty<T>` (`git grep -n "IDeploymentState<" -- backend`); `Substitute.For<IDeploymentState<T>>()` no longer
  calls the listener in `View` (a member of the interface): the test makes the call itself (peace-data-reborn `GameServerBalancerTests`).
- Optional, every game with `Orchestration/Coordinator/DeployIdentity.cs`: `git grep -n "AddPipeRequestHandler<DeployIdRequest" -- backend`
  - bind the handler to `_deployContext.DeployLifetime` right after `await _deployContext.Set(deployId, lifetime)`. The framework already
  follows only a newer deploy (`DeployState.CreatedAt`); with the binding the old coordinator stops answering in the pipe at once.

Check the behaviour:
- A call of a grain without `[Transaction]` that reads or writes `State` / `EventState` while a transaction is open on it throws
  `InvalidOperationException` (before, it wrote the uncommitted changes of the transaction into the database): `git grep -ln "\[Reentrant\]" -- backend` and the methods without
  `[Transaction]` that touch the state - make them transactional or retry.
- `SideEffectsOptions.MaxRetryCount` is the number of attempts: 5 gives 5 attempts (before: 6).
- `Connection` closes also without `Run` when its lifetime ends (before, the gateway waited for `Closed` forever).
- The open lobbies of a fallen server leave the snapshot of the observers (`LobbyRegistry` checks the servers against discovery once every 5 s).
- New fields of stored states: `DeployState.CreatedAt`, `LobbyRegistryState.HiddenServers` (old rows are read); games with
  pinned JSON of the states (`StoredStatesFormatTests`) update the references.
- `MatchMetricsOptions.ServerLastWriteRetry` (5 s): the last flush of the server stream is retried within `CloseGrace`.

### 2. Core: dead code removed (BREAKING)

Who: the client, games that call the removed members of core (at the time of the removal no game has calls).

Removed `FloatValue` (a ScriptableObject, not a single asset), `TweenExtensions.MoveAnchored`,
`ProgressionExtensions.CurveDeltaProgression`.
Search: `git grep -nwE 'FloatValue|MoveAnchored|CurveDeltaProgression' -- client/Assets` and
`git grep -n '5f70cb9f93b24939b6397c2d7338017b' -- client/Assets` (assets of `FloatValue`). Replace what is found with own code of the game:
`MoveAnchored` - `updater.Tween(lifetime, time, ease, f => target.anchoredPosition = Vector2.LerpUnclamped(start, end, f))`.

### 3. The catalogue generators fail on a broken input

Who: the client, every game with catalogues (prefabs, assets, audio, sprites, scenes).
Search: Regenerate All in the editor of the game (or Project Tools, Run All) and the log: before, there were `Included ... has empty group`, `Identifier is empty`,
`Failed to load`, `is not an EnvAsset`, `No sprites found`.
Do: before, such an input was logged and skipped, and the cleanup deleted the asset of the group and its class; now the generator throws
`InvalidOperationException` with the path before any write, and the catalogue is not updated until the input is fixed (the group, the file name, the import).
A file in Assets without an importer (not imported) is an error too; folders Unity does not import (`~`, hidden) are skipped.
Also a sprite with `tagSpeeds` without `fps` is now a markup error, not 0.

### 4. Animations: the rotatable sprite animation removed (BREAKING)

Who: the client, games with the module `animations` (peace-data-reborn, pixel-swarm; none of them uses it).
Search: `git grep -nE 'RotatableSpriteAnimation|RotatableFrameProvider|IAnimationRotationProvider|FiveAnimationDirection' -- 'client/Assets/*.cs'`
Do: removed `RotatableSpriteAnimation`, `RotatableFrameProvider`, `IAnimationRotationProvider`, `FiveAnimationDirection`;
`SpriteAnimationVariants.cs` renamed to `ForwardSpriteAnimation.cs` (the same guid). If the search found anything, keep an own copy in the game.

### 5. Flow: `MockEntry.Process` returns `UniTask` (BREAKING)

Who: the client, every game with scene mocks.
Search: `git grep -n 'UniTaskVoid Process' -- 'client/Assets/*.cs'`

in an own base of the mocks, if it redeclares the method). `MockSwitcher` runs it through `.NoAwait()`.
