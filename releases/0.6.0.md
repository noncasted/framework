## Шаги

Поиск везде из корня игры. Нет совпадений: шаг пропускается.

### 1. Консоль: статистика онлайна, Home без инфраструктурных карточек (BREAKING)

Кому: бэкенд и консоль всех игр. `HomeInfrastructureSection` удалён (его карточки теперь только на `/infrastructure`).

Поиск: `git grep -nE 'HomeInfrastructureSection|ConnectedUsersWidget|SetupCoordinator|ConnectedUsersLiveData' -- 'backend/*'`

- Сборка не упадёт: Razor на неизвестный элемент даёт только предупреждение `RZ10012` и рисует пустой тег, Home станет пустым. Искать
  поиском выше или `RZ10012` в логе сборки.
- Учёт онлайна (`backend/Cluster/Monitoring/Online`): в `SetupCoordinator` (`Orchestration/Extensions/ProjectsSetupExtensions.cs`) вызвать
  `builder.AddOnlineTracker()`, только на координаторе. Источник: `ConnectedUsersLiveData`, который игра уже пишет; пользователь считается
  по id (две вкладки или два гейтвея = 1). Читать на любом хосте: `IDeploymentState<OnlineStatsLiveData>` (регистрирует `AddMonitoring`).
  Игра, которая `ConnectedUsersLiveData` не пишет (storytale-workshop), получит ноль; трекер и виджет ей по желанию.
- Тесты игры, перечисляющие состояния фреймворка, получают два новых: `Cluster.Monitoring.Online.OnlineDayState` (`state_online_days`,
  `online_day`, ключ `Integer`) и `Cluster.Monitoring.Online.OnlineStatsLiveData` (`cluster`, `deployment_state_OnlineStatsLiveData`,
  ключ `Guid`, deploy-scoped). `Tools/Tests/Codegen/StatesLookupGeneratorTests.cs` (`_productionStates`; падает в pixel-swarm и
  storytale-workshop, проверено), `Tools/Tests/Cluster/DeployCleanupTests.cs` (список deploy-scoped типов и их identity, как у
  `ConnectedUsersLiveData`; pixel-swarm, peace-data-reborn, mines-leader). Пример: `tools/framework/backend/Tests/Cluster/DeployCleanupTests.cs`.
- Home консоли (`Console/Home/HomeSections.razor`, `Home.razor`): `<HomeInfrastructureSection />` -> `<HomeClusterSection />` (Features и
  Client Telemetry, последняя только с `AddClientTelemetryReader`); свой `ConnectedUsersWidget` удалить, на его место `<OnlineWidget />`
  (текущий онлайн, пик и уникальные по часам / дням, клик по заголовку открывает `/online`). Остальные карточки, карточки игры
  (`AddConsoleInfrastructureCard`) и новая `Online` - на `/infrastructure`. `ConsoleInfrastructureCard` переехал в `Console/Infrastructure`,
  пространство имён то же (`Console`). Комментарий в `GameModule.cs` про `ConnectedUsersWidget` и регистрация ради него (`IUserCollection`
  для имён) - удалить, если больше никому не нужны.
- Страница `/online` (`ConsoleConstants.Pages.Online`) берётся из сборки `Console`, ничего регистрировать не надо. Классы Tailwind - только
  те, что уже есть в `app.css` всех игр, пересобирать `app.css` не нужно.

## Проверить поведение

- Home консоли: слева `HomeClusterSection` (Features, Client Telemetry), справа `OnlineWidget`. В Home игры уже есть свой
  `FeaturesStatusWidget` (все четыре игры): Features окажется дважды, лишнее убрать по вкусу.
- `/infrastructure`: карточки игры перед карточками фреймворка, среди них новая `Online`.
- Postgres: подключение как раньше, 10 попыток раз в секунду; после последней исключение называет число попыток (было пустое `Exception`).
- `PeerMesh`: игрок, запустивший сетку позже своего входа (поздний игрок), теперь получает прямое соединение, а не туннель после таймаута.

## Без действий

- Postgres: `PostgresConnect:Attempts` и `PostgresConnect:RetryDelayMs` конфигурации (по умолчанию 10 и 1000), меньше 1 попытки бросает;
  storytale-workshop уже ставит `PostgresConnect__Attempts=1` в `PostResourcesSetupTests`.
- `network`: `PeerSignaling` держит последнее согласование пира без канала (offer и сигналы после него) до первого подписчика канала к
  нему; тест `OfferBeforeMeshRun_Direct`. API не менялся.
- `deploy-client`: необязательные хуки `preflight` (до снапшота, и с `--notest`, может перегенерировать файл дерева) и `beforeUpload`
  (после сборок, до первой выгрузки, не с `--no-deploy`) в `.claude/deploy-client.json`; упавший хук останавливает запуск. Источник:
  pixel-swarm, уже настроены. Доходит по ссылке на скилл; копии скилла в mines-leader и peace-data-reborn его не знают.
- `split-commit`: коммитит сразу после плана, без подтверждения. Доходит по ссылке; копии в mines-leader и peace-data-reborn старые.
