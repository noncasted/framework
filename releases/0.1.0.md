# 0.1.0

## Шаги: клиент

Поиск везде из корня игры. Нет совпадений: шаг пропускается. Совпадение может оказаться уже новой формой (`new DeployState()`, конструктор с
аргументами): менять только старую.

### 1. Методы `IScope*Async` без суффикса

Имена интерфейсов прежние (`IScopeSetupAsync`), меняются только методы: `OnSetupAsync` -> `OnSetup`, также `OnBaseSetup`,
`OnSetupCompletion`, `OnLoaded`, `OnDispose`. Методы теперь совпадают с синхронными, поэтому класс не может реализовать
`IScopeSetup` и `IScopeSetupAsync` сразу: такой класс объединяет обе работы в одном методе.

Поиск: `git grep -nE 'On(BaseSetup|Setup|SetupCompletion|Loaded|Dispose)Async' -- 'client/Assets/*.cs'`

### 2. `PlayAsync` и `RunCustomAsync`

`IAnimation.PlayAsync` -> `PlayAwaited`, `IEventLoop.RunCustomAsync` -> `RunCustomAwaited`.

Поиск: `git grep -nE '\.PlayAsync\(|\bRunCustomAsync\b' -- 'client/Assets/*.cs'`

### 3. `ListenBack` без updater

`back.ListenBack(lifetime, updater, onBack)` -> `back.ListenBack(lifetime, onBack)`. Поле `IUpdater`, которое больше ни для чего
не нужно, удалить вместе с параметром конструктора. Расширение `BackInputExtensions` удалено, это метод `IBackInput`.

Поиск: `git grep -n 'ListenBack(' -- 'client/Assets/*.cs'`

### 4. `IPlatformAuth.GetCredentials`

`GetTelegramInitData()` и `GetSteamTicket(lifetime)` заменены одним `await GetCredentials(lifetime)`: в `Ticket` лежит initData или
тикет, в `Name` имя Steam. Пример: `client/Assets/Meta/MetaLoop.cs` в коммите `0e1bd5b4` pixel-swarm.

Поиск: `git grep -nE 'GetTelegramInitData|GetSteamTicket' -- 'client/Assets/*.cs'`

### 5. `AddSteam` и `ISteamClient`

`AddSteam(options)` -> `AddSteam(options, platformOptions)`, `ISteamClient` удалён. Вне Steam регистрируются варианты `NoPlatform*`.

Поиск: `git grep -nE '\bAddSteam\(|\bISteamClient\b' -- 'client/Assets/*.cs'`

### 6. `InputConstraints` в `Global.UI`

Добавить `using Global.UI;` там, где тип перестал находиться.

Поиск: `git grep -lw InputConstraints -- 'client/Assets/*.cs'`

Поиск: `git grep -nE 'ButtonSounds\.(Clicked|Hovered)' -- 'client/Assets/*.cs'`

### 8. `ClientOutdatedNoticeStyle` через конструктор

Первый аргумент обязательный шрифт, остальные именованные, неуказанный оставляет значение по умолчанию:
`new ClientOutdatedNoticeStyle { Font = x, PanelColor = y }` -> `new ClientOutdatedNoticeStyle(x, panelColor: y)`. Пример:
`GlobalUIExtensions.cs` в коммите `0d12695d` pixel-swarm. Уведомлению нужен `IUINavigation`, значит в scope есть `AddUI` или
`AddUINavigation`.

Поиск: `git grep -nE 'new ClientOutdatedNoticeStyle|AddClientOutdatedNotice|AddUINavigation|\bAddUI\(' -- 'client/Assets/*.cs'`

### 9. `ViewableDictionary.Set`

Индексатор только читает: `dict[key] = value` -> `dict.Set(key, value)`, смысл тот же (добавить или заменить). Запись через индексатор
поиск не отличает от чтения, остальное покажет компилятор (`CS0200`). Известно: `PlayerModifiers` в mines-leader,
`ObjectEditCollidersModel` (`_switches`, `_visibility`) в storytale-workshop.

Поиск: `git grep -lE 'ViewableDictionary<' -- 'client/Assets/*.cs'`

### 10. Оси геймпада в `InputManager.asset`

`AddInput` бросает при сборке scope, если в `client/ProjectSettings/InputManager.asset` нет осей `Gamepad Axis 1..10`
(тип joystick axis, ось N-1). Блок можно скопировать из того же файла pixel-swarm. Касается игр, вызывающих `AddInput` модуля `inputs`:
в storytale-workshop `AddInput` свой, ему оси не нужны.

Поиск: `git grep -c 'Gamepad Axis' -- client/ProjectSettings/InputManager.asset` (нужно 10)

```csharp
// стало

```

Пример: `OrleansTestClusterFixture.cs` в коммите `0d12695d` pixel-swarm.

Поиск: `git grep -nE '\.(LockWaitSeconds|StuckGraceSeconds) *=|RegisterConfig' -- 'backend/*.cs'`

### 15. `IEventStateValue.Id` (по желанию)

Игра компилируется без правок: `Id` в интерфейсе только читается. Чтобы убрать публичный сеттер у агрегата, допустимы

снимок теряет события без ошибки (теперь `EventStorage.Read` на этом бросает).

Поиск: `git grep -nE 'IEventStateValue' -- 'backend/*.cs'`

## Проверить поведение

Компилятор этого не покажет.

- **Генератор контейнера.** Был неверный код без ошибки: не создавались объекты, подменялись параметры, не вызывался `[Inject]`. Теперь
  код правильный или есть диагностика `CINGR*`, и игра могла опираться на старое поведение. Все сборки перекомпилируются с новым
  `ContainerGenerator.dll`, первая компиляция долгая. После неё прочитать все `CINGR` (известно: `CINGR015` в storytale-workshop).
- **Завершение scope.** Корни сущностей получают `ScopeLifetime`, порядок разрушения изменился. Проверить выход из матча и повторный вход.
- **Интерфейс.** `Process` и `ProcessStack` закрывают состояние без обработчика входа по завершении вызова. Одно нажатие «назад» закрывает
  только последнее окно. Проверить вложенные окна и возврат.
- **Сокеты.** Ошибка обработчика больше не останавливает цикл сокета (`SocketInbox`, `SocketPump`), но видна в логе. Конец lifetime во время
  `WebRtcPeerSocket.Connect` теперь `OperationCanceledException`, а не отказ канала, и туннель не открывается.
- **Каталоги.** Спрайт без группы попадает в лог. Атлас со спрайтами нескольких групп становится shared entry (`SharedAddressablesSync`):
  после Regenerate All возможны изменения в группах Addressables, и пересборка бандлов их отражает.
- **Профайлер.** `ProfilerFrameCapture` выключен по умолчанию и хранит состояние в SessionState. Для записи включить явно.
- **Консоль.** Форма опций больше не делит объект с живой конфигурацией; сохранение без изменений не будит слушателей значения.

## Необратимое: формат ассетов

Записи каталогов теперь хранят данные в новых ключах (`_name`, `_clip`, ...). Старые ассеты читаются через `FormerlySerializedAs`,
пересохранять их специально не надо. Но ассет, пересохранённый на новом framework, ветка на старом framework читает как значения по
умолчанию. Пока ветка игры (например `game-audio`) не обновлена, сгенерированные ассеты из обновлённой ветки в неё не вливать.

## Без действий

- Разрез больших файлов: типы разнесены по файлам, пространства имён те же. `.meta` сохранены, ссылки ассетов не меняются.
- Удалён код, которым не пользуется ни одна игра (проверено по HEAD и по GUID в ассетах): `MathUtils`, `TransformUtils`, `ScriptableCurve`,
  `SerializableCurve`, `UpdatableTimer`, `SafeAreaLayout`, `RectTransformExtensions`, элементы `Design*` и `*ElementConfig` модуля `ui`.

- `NetworkConnection` берёт `IWebSocketFactory` (`6ee8ad8`): `AddNetworkConnection` регистрирует его сам, ни одна игра не создаёт соединение вручную.
- Опции кластера (`ClusterStartupOptions`, `ServiceDiscoveryOptions`, `CoordinatorHealthOptions`) стали `init`: сигнатуры `ConfigureRequiredServices`,
  `PublishGameServerUrl` прежние.
- Форки: addressables без утечки `AssemblyLoad` в редакторе, окно настройки unity-mcp открывается только из меню.
- Скиллы `control`, `start-cluster`, `update-override-packages`, `auto`, `code-audit` и документы `.claude/docs` обновлены, ссылки подхватывают их сами.
