# 0.1.0

The first release: 117 commits of 2026-11-02 (`63401a9..d8b482d`). An audit of the client, big files cut without a change of behaviour, the
types of the framework have no public setters and fields. Fixed: the silent errors of the container generator and a memory leak of the editor of 200-300 MB
on every domain reload. A game has to fix its calls of the client API and the backend tests; the assets and the saves stay readable.

## Steps: client

Search everywhere from the root of the game. No matches: the step is skipped. A match may already be the new form (`new DeployState()`, a constructor with
arguments): change only the old one.

### 1. The methods of `IScope*Async` without the suffix

The interface names stay (`IScopeSetupAsync`), only the methods change: `OnSetupAsync` -> `OnSetup`, also `OnBaseSetup`,
`OnSetupCompletion`, `OnLoaded`, `OnDispose`. The methods now match the synchronous ones, so a class cannot implement
`IScopeSetup` and `IScopeSetupAsync` at once: such a class joins both works in one method.

Search: `git grep -nE 'On(BaseSetup|Setup|SetupCompletion|Loaded|Dispose)Async' -- 'client/Assets/*.cs'`

### 2. `PlayAsync` and `RunCustomAsync`

`IAnimation.PlayAsync` -> `PlayAwaited`, `IEventLoop.RunCustomAsync` -> `RunCustomAwaited`.

Search: `git grep -nE '\.PlayAsync\(|\bRunCustomAsync\b' -- 'client/Assets/*.cs'`

### 3. `ListenBack` without the updater

`back.ListenBack(lifetime, updater, onBack)` -> `back.ListenBack(lifetime, onBack)`. A field `IUpdater` that is no longer needed for anything
is deleted together with the parameter of the constructor. The extension `BackInputExtensions` is removed, it is a method of `IBackInput`.

Search: `git grep -n 'ListenBack(' -- 'client/Assets/*.cs'`

### 4. `IPlatformAuth.GetCredentials`

`GetTelegramInitData()` and `GetSteamTicket(lifetime)` are replaced by one `await GetCredentials(lifetime)`: `Ticket` holds the initData or
the ticket, `Name` the Steam name. Example: `client/Assets/Meta/MetaLoop.cs` in the commit `0e1bd5b4` of pixel-swarm.

Search: `git grep -nE 'GetTelegramInitData|GetSteamTicket' -- 'client/Assets/*.cs'`

### 5. `AddSteam` and `ISteamClient`

`AddSteam(options)` -> `AddSteam(options, platformOptions)`, `ISteamClient` removed. Off Steam the variants `NoPlatform*` are registered.

Search: `git grep -nE '\bAddSteam\(|\bISteamClient\b' -- 'client/Assets/*.cs'`

### 6. `InputConstraints` in `Global.UI`

Add `using Global.UI;` where the type is no longer found.

Search: `git grep -lw InputConstraints -- 'client/Assets/*.cs'`

### 7. `ButtonSounds.Bind`

```csharp
// before
ButtonSounds.Clicked = onClick;
ButtonSounds.Hovered = onHover;
lifetime.Listen(() => { ButtonSounds.Clicked = null; ButtonSounds.Hovered = null; });
// after
ButtonSounds.Bind(lifetime, onClick, onHover);
```

Search: `git grep -nE 'ButtonSounds\.(Clicked|Hovered)' -- 'client/Assets/*.cs'`

### 8. `ClientOutdatedNoticeStyle` through the constructor

The first argument is the required font, the others are named, an omitted one keeps the default value:
`new ClientOutdatedNoticeStyle { Font = x, PanelColor = y }` -> `new ClientOutdatedNoticeStyle(x, panelColor: y)`. Example:
`GlobalUIExtensions.cs` in the commit `0d12695d` of pixel-swarm. The notice needs `IUINavigation`, so the scope has `AddUI` or
`AddUINavigation`.

Search: `git grep -nE 'new ClientOutdatedNoticeStyle|AddClientOutdatedNotice|AddUINavigation|\bAddUI\(' -- 'client/Assets/*.cs'`

### 9. `ViewableDictionary.Set`

The indexer only reads: `dict[key] = value` -> `dict.Set(key, value)`, the meaning is the same (add or replace). The search does not tell a write through the indexer
from a read, the compiler shows the rest (`CS0200`). Known: `PlayerModifiers` in mines-leader,
`ObjectEditCollidersModel` (`_switches`, `_visibility`) in storytale-workshop.

Search: `git grep -lE 'ViewableDictionary<' -- 'client/Assets/*.cs'`

### 10. The gamepad axes in `InputManager.asset`

`AddInput` throws at the build of the scope if `client/ProjectSettings/InputManager.asset` has no axes `Gamepad Axis 1..10`
(type joystick axis, axis N-1). The block may be copied from the same file of pixel-swarm. Concerns the games that call `AddInput` of the module `inputs`:
in storytale-workshop `AddInput` is its own, it needs no axes.

Search: `git grep -c 'Gamepad Axis' -- client/ProjectSettings/InputManager.asset` (10 needed)

### 11. Static settings and the models of the catalogues

There are no more public setters. A compile error `CS0200` or `CS0272` on one of these types is fixed like this:

| Before | After |
|--------|-------|
| `ProfilerTraceStorage.ColdDomain = v` | `SetColdDomain(v)` |
| `ReactiveExceptions.Handler = h`, `NoAwaitExceptions.Handler = h` | `SetHandler(h)`, `null` removes it |
| `LifetimeTracker.Current = t` | `Install(t)` |
| `LifetimeAnalytics`, `ContainerRegistryDebug`, `ProfilerFrameCapture` `.Enabled = v` | `SetEnabled(v)` |
| a write into `PlatformOptions` (the mobile check) | `SetMobileCheck` |
| a write of the handler into `ObjectBindings` | `SetRegenerateHandler` |
| `GamepadState.LeftStick = v` | `SetLeftStick(v)`, also `RightStick`, `LeftTrigger`, `RightTrigger` |
| `new AudioCatalogMetadata { Included = true, Group = g }` | `new AudioCatalogMetadata(true, g)`, also `Asset`, `Prefab`, `Sprite` |
| `nameof(SpriteEntry.Name)`, `FindPropertyRelative("Name")` on the records of catalogues | `SpriteEntry.NameKey`, the constants `*Key` next to the record |
| `ColorGroup.Entries` as a mutable list | read only, `IReadOnlyList` |

Keys: `FindPropertyRelative` with the old string silently returns `null`, the compiler does not show it. Records: `EnvAssetEntry`,
`AudioAssetEntry`, `ColorEntry`, `ColorGroup`, `PrefabAssetEntry`, `SpriteEntry`, `SystemLanguageMapping`.

Search: `git grep -nE 'ProfilerTraceStorage\.ColdDomain *=|(ReactiveExceptions|NoAwaitExceptions)\.Handler *=|LifetimeTracker\.Current *=|new (Audio|Asset|Prefab|Sprite)CatalogMetadata|nameof\((SpriteEntry|ColorGroup|ColorEntry|AudioAssetEntry|EnvAssetEntry|PrefabAssetEntry)\.|FindPropertyRelative\(' -- 'client/Assets/*.cs' ':!client/Assets/Plugins'`

## Steps: backend

Almost everything is in `backend/Tools/Tests`, the working code of the games is not touched.

### 12. `SessionData` through the constructor

`new SessionData { ... }` -> `new SessionData(type, expectedUsers, id, lifetime)`, the properties are read only. In the test worlds.

Search: `git grep -n 'new SessionData\b' -- 'backend/*.cs'`

### 13. Options became records

`TransactionOptions`, `TaskBalancerOptions`, `SideEffectsOptions`, `DurableQueueOptions` change through `with`. In `RegisterConfig`
of the test fixture `Action<TOptions>?` -> `Func<TOptions, TOptions>?`:

```csharp
// before
o => { o.LockWaitSeconds = 2f; o.StuckGraceSeconds = 5f; }
// after
o => o with { LockWaitSeconds = 2f, StuckGraceSeconds = 5f }
```

Example: `OrleansTestClusterFixture.cs` in the commit `0d12695d` of pixel-swarm.

Search: `git grep -nE '\.(LockWaitSeconds|StuckGraceSeconds) *=|RegisterConfig' -- 'backend/*.cs'`

### 14. Cluster states through methods

| Type | After |
|------|-------|
| `DeployState` | `Init(id, now)`, `Heartbeat`, `MarkCoordinatorReady` |
| `ClusterFeaturesState` | `SetAcceptingConnections`, `SetSideEffectsEnabled`, `SetCoordinatorUnhealthy`, `SetGameFlag` |
| `LobbyRegistryState` | `AdvanceListingVersion` (`Entries` only `init`) |
| `LobbyRegistryEntry` | `MarkStarted`, `UpdateListing` |
| `HeapSnapshotResponse` | `SetGcMemory`, `SetTopTypes`, `SetError`, `SetCollectDuration` |
| `TransactionContext.ExceptionMessage` | `SetExceptionMessage` |

Orleans messages and stored records became `init`: object initializers compile, an assignment after the creation does not. The JSON format
in the database did not change, no migration needed. Example: `DeployCleanupTests.cs` in the commit `0d12695d` of pixel-swarm.

Search: `git grep -nE 'new (DeployState|ClusterFeaturesState|LobbyRegistryState|LobbyRegistryEntry)\b|\.(AcceptingConnections|LastHeartbeat|ListingVersion) *=' -- 'backend/*.cs'`

### 15. `IEventStateValue.Id` (optional)

The game compiles without changes: `Id` is only read in the interface. To remove the public setter of an aggregate,
`[Id(0)] [JsonProperty] public string Id { get; private set; }` or `{ get; init; }` are allowed. **`private set` without `[JsonProperty]` is not**:
the snapshot loses events without an error (now `EventStorage.Read` throws on it).

Search: `git grep -nE 'IEventStateValue' -- 'backend/*.cs'`

## Check the behaviour

The compiler does not show this.

- **Container generator.** There was wrong code without an error: objects were not created, parameters were swapped, `[Inject]` was not called. Now
  the code is right or there is a diagnostic `CINGR*`, and the game may have relied on the old behaviour. All the assemblies recompile with the new
  `ContainerGenerator.dll`, the first compilation is long. After it read every `CINGR` (known: `CINGR015` in storytale-workshop).
- **Scope disposal.** The roots of entities get `ScopeLifetime`, the order of destruction changed. Check leaving a match and entering again.
- **Interface.** `Process` and `ProcessStack` close a state without an enter handler when the call completes. One press of "back" closes
  only the last window. Check nested windows and the return.
- **Sockets.** An error of a handler no longer stops the loop of the socket (`SocketInbox`, `SocketPump`), but is seen in the log. The end of a lifetime during
  `WebRtcPeerSocket.Connect` is now `OperationCanceledException`, not a refusal of the channel, and the tunnel does not open.
- **Catalogues.** A sprite without a group goes to the log. An atlas with sprites of several groups becomes a shared entry (`SharedAddressablesSync`):
  after Regenerate All the Addressables groups may change, and a rebuild of the bundles reflects them.
- **Profiler.** `ProfilerFrameCapture` is off by default and keeps its state in SessionState. Turn it on explicitly to record.
- **Console.** The options form no longer shares an object with the live configuration; a save without changes does not wake the listeners of the value.

## Irreversible: the format of the assets

The records of the catalogues now keep their data in new keys (`_name`, `_clip`, ...). Old assets are read through `FormerlySerializedAs`,
there is no need to resave them on purpose. But an asset resaved on the new framework is read by a branch on the old framework as default
values. Until a branch of the game (for example `game-audio`) is updated, do not merge into it the generated assets of an updated branch.

## Pointer older than the base

If `status.sh` says the pointer is older than `63401a9`, go through these changes first. Details in the commit message:
`git -C tools/framework show <hash>`. What the compiler covers is not noted here: the steps were checked only by a backend build, the first
game completes this list.

### A1. `Framework.Common` (`61670d2`)

The reactive primitives moved to `common/`. Add the package to `client/Packages/manifest.json`, `GUID:3ea5c3f1172040daa713d5ad71728b78` to
every asmdef with a reference to `Internal`, a reference to `framework.common.csproj` to every backend csproj. `using Common.Reactive` -> `using Internal`.
Without it the build of mines-leader fails with `CS0012`.

### A2. Lobbies and the hosting of sessions (`61670d2`)

`LobbyCode` and the lobby protocol are now in `shared/Lobbies`, `shared/Matchmaking`, the hosting in `backend/Hosting`. Delete your own copy from the game project,
otherwise `CS0433` (peace-data-reborn: `Cluster.Game/Lobbies/LobbyCodeGenerator.cs`). List the protocol tags `NetworkContextTags.Session*`, `Lobb*`
in the union of the game.

### A3. The session core (`8a9e228`)

The logic of sessions is in `Framework.Session.Core`: a reference to `shared/SessionCore/framework.session.core.csproj` next to `Session.csproj`. `IUser.Connection`
is now `IUserConnection`, commands log through `ISessionLog`, `IServiceFactory.OnSessionCreated` -> `IExecutionQueue.SetupServices(factory)`,
`LocalSessionService` removed. The tags `PeerSignal` 70, `PeerTunnel` 71 in the union of the game.

### A4. The animations module (`d003830`)

Sprite animations are in the optional package `client/modules/animations`, assembly `Internal.Animations`. Add it to the manifest and the asmdef if the game uses them.

### A5. Review fixes (`d211f8a`) and input constraints (`425794b`)

Separate changes of API and behaviour: the **BREAKING** list in `docs/changes/2026-10-26-review-fixes.md`. Among them the required
`ProjectSettings/Framework.json`, and `InputConstraints` is no longer an enum.

### A6. Docs and skills (`63401a9`)

The shared docs and skills are now in the framework: the import of the index and the links are described in `CLAUDE.md` of the framework (sections Docs and Skills). Example: the commit
`b6cf2065` of pixel-swarm.

### A7. `AddTelegramAPI` and `TelegramEditorOptions` (`d211f8a`)

Who: the client of games with the platform `telegram` (at the time of the release peace-data-reborn; pixel-swarm is already updated).
Search: `git grep -n 'AddTelegramAPI' -- 'client/Assets/*.cs'`
Do: `builder.AddTelegramAPI(platformOptions)` -> `builder.AddTelegramAPI(platformOptions, editorOptions)`. `TelegramEditorOptions(botTokenSettingsPath)`
sets the path (from the folder of the Unity project) to the settings file of the local backend with `TelegramBotToken`: the debug API in the editor signs the init data with it the same
way as Telegram, and the local meta checks it with the same token. Example: `GlobalPublisherExtensions.cs` of pixel-swarm,
`new TelegramEditorOptions("../backend/Orchestration/Aspire/appsettings.local.json")`. Without the file or the token `GetInitData` throws in the editor.

## No action

- The cut of big files: the types are spread over files, the namespaces are the same. `.meta` kept, the references of assets do not change.
- Removed code that no game uses (checked by HEAD and by GUID in the assets): `MathUtils`, `TransformUtils`, `ScriptableCurve`,
  `SerializableCurve`, `UpdatableTimer`, `SafeAreaLayout`, `RectTransformExtensions`, the elements `Design*` and `*ElementConfig` of the module `ui`.
- `SettingsSave` of the module `settings` (`Set*Volume`, without `Language`): no game plugs in the module, each has its own `SettingsSave`.
- `NetworkConnection` takes `IWebSocketFactory` (`6ee8ad8`): `AddNetworkConnection` registers it itself, no game creates a connection by hand.
- The cluster options (`ClusterStartupOptions`, `ServiceDiscoveryOptions`, `CoordinatorHealthOptions`) became `init`: the signatures of `ConfigureRequiredServices`,
  `PublishGameServerUrl` stay.
- Forks: addressables without the `AssemblyLoad` leak in the editor, the settings window of unity-mcp opens only from the menu.
- The skills `control`, `start-cluster`, `update-override-packages`, `auto`, `code-audit` and the docs `.claude/docs` updated, the links pick them up by themselves.
