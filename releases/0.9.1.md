# 0.9.1

1 коммит (`v0.9.0..a2fadb9b`), только `deploy-client`: проверка контента в `checks <t>` (`verify.sh`) искала имена бандлов в `.data`
простым текстом, а каталог (`Resources`) лежит в `data.unity3d`, архиве UnityFS из блоков LZ4, и каждый не предзагруженный бандл падал с
`the catalog in the .data file does not name`. Теперь `deploy-client/webdata.py` распаковывает архивы `.data` перед поиском. Кода,
ассетов и зависимостей нет, действий от игры нет, поменять только указатель.
