# 0.9.1

1 commit (`v0.9.0..a2fadb9b`), only `deploy-client`: the content check in `checks <t>` (`verify.sh`) looked for the names of the bundles in `.data`
as plain text, while the catalog (`Resources`) lies in `data.unity3d`, a UnityFS archive of LZ4 blocks, and every bundle that is not preloaded failed with
`the catalog in the .data file does not name`. Now `deploy-client/webdata.py` unpacks the archives of `.data` before the search. No code,
assets or dependencies, no action from the game, only move the pointer.
