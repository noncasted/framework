# 0.18.2

1 commit (`v0.18.1..90bb18e7`): the folder tree of a task. `GAMEPLAY_ARCHITECTURE.md` fixes the layout of a gameplay assembly as a tree of
cells (`Loop`, `<Feature>/{Definitions, Entity/{Root, Components, States, Sync}, Services, <SubFeature>}`, `Services`, `<Utility>`,
`Common`, `Assets`). `plan-architecture` lays every new or moved file of a task into these cells (Step 4b, `### Folder tree` in
`_info.md`) and asks the user to approve the tree before the steps. `orchestrate --architecture` starts no code step before the
approval, and its agents create no folder outside the tree. Only docs and skills changed. The game has nothing to do.
