# 0.18.1

3 commits (`v0.18.0..a58a4bb9`): the skills drop oh-my-pi (`omp`). Cheap agents now run in Claude Code on OpenCode Go, in the
profile `~/.claude-opencode` (the `clo` alias). `audit-swarm` spawns `audit-scout` / `audit-verifier` with the Agent tool. They are
Claude Code agents with `model: inherit`, and `install.sh` links them into `~/.claude-opencode/agents`, no longer `~/.omp`.
`context_meter.py` of `orchestrate` finds the transcripts of that profile too: before, an orchestrator in `clo` got "no transcript". The game
has nothing to do.

## Once per machine, not per game

- The profile `~/.claude-opencode` with an OpenCode `ANTHROPIC_BASE_URL` in its `settings.json` (the `clo` alias).
- `bash tools/framework/.claude/skills/audit-swarm/install.sh`: links the agents into `~/.claude-opencode/agents`
  (`CLAUDE_CONFIG_DIR=<dir>` for another profile). The old links in `~/.omp/agent/agents` and the `task.*` limits of omp are no longer used.

## No action

- `audit-swarm`: Agent tool instead of the `task` tool of omp, at most ~12 agents a message, no runtime limit of omp (the size of a package keeps a scout short).
- `.claude/skills/CLAUDE.md`: cheap agents run in the OpenCode Go profile. A hook of that profile drops the `model` / `effort` of Agent calls, so the per-step models of `orchestrate` apply only in the Anthropic profile.
- `context_meter.py`: transcripts of the calling profile (`CLAUDE_CONFIG_DIR`) first, then every `~/.claude*` profile.
