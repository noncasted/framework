## Итог

Исправлять первыми:

#### G1. Альтернативы группируются по общему сервису, а не по одному `if`
- Где: `client/core/Source~/ContainerGenerator/Scope/ScopePlan.cs:430`, `Scope/ScopeEmitter.cs:213`
- Правило: баг
- Проблема: `if (a) Register<A>().As<IScopeSetup>(); if (b) Register<B>().As<IScopeSetup>();` попадают в одну группу с одним полем. При `a && b` объект `B` молча не создаётся, `VerifyCovered` это пропускает.
- Как исправить: `GraphWalker` присваивает `BranchGroup` на каждый `if` / `switch` и пишет его в blob манифеста, группировка идёт по нему.

#### G2. В группе альтернатив всё решает последний член
- Где: `Scope/ScopeEmitter.cs:167`, `Scope/ScopePlan.cs:953`, `Scope/ScopePlan.cs:831`
- Правило: баг
- Проблема: `[Inject]` только у неглавной ветки не вызывается. `IDisposable` только у неё не освобождается, а только у главной даёт `InvalidCastException` в `Dispose`. Экспортируется только `FieldType`: `As<IB>` из дочернего scope уходит к родителю и бросает.
- Как исправить: `[Inject]` в каждой ветке выбора, `is IDisposable` в `Dispose`, экспорт сервисов всех членов с проверкой типа.

#### G3. Transient-альтернатива игнорирует выбранную ветку

- Как исправить: `Create*`, аргументы и списки выбирают реализацию через сохранённый `IsRegistered`, либо новая диагностика запрещает случай.

#### G4. Цепочка регистрации уходит не на тот объект
- Где: `Graph/GraphWalker.cs:973`, `:214`

- Как исправить: сначала локальная переменная-получатель, `LastRegistration` только для цепочки без неё; `ordinal` на месте вызова.

#### G5. `WithParameter` проигрывает регистрации того же типа
