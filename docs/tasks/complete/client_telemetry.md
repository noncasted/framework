## Телеметрия клиентов — Результат

### Что сделано
- Модуль `client/modules/telemetry`: базовые коллекторы, ошибки со `Scrubber`, сессии на lifetime с тегами, трейс запуска, транспорт на meta-сокете; сборка фрейма по фазам, GPU, WebGL, страница.
- Сервер `backend/ClientTelemetry`: грейн на сессию, два стейта, постоянный флаг, API чтения под токеном, записи запуска; приём по meta-сокету, HTTP-приём, beacon и повторы удалены.
- Консоль: список сессий с фильтром тегов, карточка, группы ошибок, окно трейса запуска как Startup Profiler.
- Скилл `client-telemetry`: `monitor --tag`, разбор сессии и трейса на проде.
- Pixel Swarm подключён и развёрнут: сессии `menu`, `lobby`, `run`; web и telegram на проде, с телефона и IPad/iPhone пришли настоящие данные.

### Что вошло в релиз 0.4.0
Релиз из её коммитов: кадр по фазам, GPU, WebGL, страница, незакрытая прошлая сессия, предупреждения, загрузки ассетов, страница до Unity в трейсе запуска; сеть без аллокаций, экранные канвасы (`IScreenCanvasCamera`), стрип WebGL-сборки, деплой без редактора (`deploy-client`), скилл `device-lab`.

- Приём переезжает с HTTP на meta-сокет, сессия равна забегу (решение пользователя, шаг 4c); хранение шага 2 заменено грейном и двумя стейтами.
- Позже (по её итогам) заведены задачи `web_perf_tools`, `web_bench_tools` и шаг стресс-тестов (`PlatformType.WebStress`, релиз 2026-11-04, прод игры `1b1d5f3d`); WEBGL_TROUBLESHOOTING.md (framework 15728825).
