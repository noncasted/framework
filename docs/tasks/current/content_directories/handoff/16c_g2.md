### Находки и решения (неочевидное, тупики и почему)
- **MEMFS и «modified while opened»**: движок сверяет время узла с моментом открытия архива. Узел MEMFS хранит `mtime/ctime/atime` в мс
  (`node.mtime = node.ctime = Date.now()` в `MEMFS.write`); `utime` из C# ставит секунды и трогает `ctime` → не помогает. Рабочий способ —
  прямое присваивание полям узла в jslib (`FS.lookupPath(path).node`). Это внутренность emscripten Unity 7000.0.0a10 (`MEMFS.getattr` читает
  `node.mtime/ctime/atime`) — fail fast в jslib, если полей нет (`typeof node.mtime !== 'number'` → throw).
- **Блоки UnityFS выровнены на 16 байт** (флаг 0x200 + выравнивание каждого блока): спан файла = `[первый блок, конец последнего)`,
  паддинг между файлами ≤ 15 байт. Читатель это проверяет.
- **Редактор не регистрирует каталог без type tree** — ошибка движка понятная; поэтому type tree выключены только в `ContentDirectoryBuilder`
  (сборка плеера), тестовые сборки PlayMode (`ContentDirectoryTestBuild`, `ContentIndexWriterTests`) — с type tree.
- Смоук-архив: 136784 байт (без type tree), заголовок 528; спаны цели включают общий с корнями файл — `Fetch` должен пропускать реальные.
- Чтение «соседних нулей» движком (read-ahead через границу файла) на смоуке не проявилось (сцена лежит сразу за корнями и загрузилась
  после дозаписи); на pixel-swarm проверит стенд.
