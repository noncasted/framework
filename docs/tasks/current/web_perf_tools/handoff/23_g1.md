## Design (decided, written)

pixel-swarm does NOT use the framework `settings` module (own `Global.Settings.Settings`, save key `Global.Settings.SettingsSave` by
`ItchSaves` FullName), so the modes are not put into `modules/settings` (would force a migration and change the save key). Instead
two new optional modules, namespaces kept (`Global.Resolution`, `Global.FrameRate`), all moved files keep their game `.meta` guids:

- `client/modules/resolution` (`com.noncasted.framework.resolution`, `Internal.Resolution` guid `9d58ab1ce6834305883a068063d7daa9`):
  `ResolutionMode`, `IResolutionSetting` (new; the game settings implement it), `IRenderPixelRatio`, `NoRenderPixelRatio`,
  `RenderResolution` (takes `IResolutionSetting`), `ResolutionExtensions.AddResolution()`, `Web/WebRenderPixelRatio` + `WebRenderResolution.jslib`
  (calls `window.renderResolution.set`). `WebTemplate~/render-resolution.js`: the renderPixelRatio logic of the old web-shell.js
  (same formula, same localStorage key `webShell.resolution`, own resize/orientation/fullscreen/visualViewport/ResizeObserver listeners,
  API `pixelRatio(canvas, max)`, `follow(module, canvas, max)`, `set(mode)`, `mode()`), put into `<head>` by `Editor/RenderResolutionInjection`
  (`BuiltPageScripts`, like audio-session.js). `Telemetry/` (`Internal.Resolution.Telemetry` guid `d79d6c118bdd48a696bea4f994e2dd01`):
  `ResolutionTelemetryCollector` (`settings.resolution`) + `AddResolutionTelemetry()`.
- `client/modules/framerate` (`com.noncasted.framework.framerate`, `Internal.FrameRate` guid `90f39b7295db4ddf82e39fa22b13988d`):
  `Runtime/` `FrameRateMode`, `IFrameRateSetting` (new), `FrameRateLimit` (takes `IFrameRateSetting`), `FrameRateExtensions.AddFrameRate(AutoFrameRateOptions)`;
  `Runtime/Auto/` AutoFrameRate, Memory (key `FrameRate.AutoLow` kept), Options, Rule, FrameWorkMeter, IAutoFrameRate; `Runtime/Request/`
  IFrameRateRequest, NoFrameRateRequest, WebFrameRateRequest, `WebFrameRate.jslib` (now parses `?fps=` itself, same rules/values).
  `Telemetry/` (`Internal.FrameRate.Telemetry` guid `f9dea762b6164ec7ac91c9f732083ae1`): `FrameRateTelemetryMarks` (`fps.auto.<n>`) + `AddFrameRateTelemetry()`.
- Both `*.Telemetry` asmdefs: `defineConstraints FRAMEWORK_TELEMETRY` + versionDefine of package `com.noncasted.framework.telemetry`.
  `client/project/ProjectSettings/ProjectSettings.asset`: `FRAMEWORK_TELEMETRY` added to Standalone and WebGL defines (modules are Assets there, not packages).
- Tests: `framerate/Tests/Editor` (`Internal.FrameRate.Tests`): `AutoFrameRateRuleTests` (moved, 9), `FrameRateLimitTests` (moved minus 2 game tests, 7);
  `resolution/Tests/Editor` (`Internal.Resolution.Tests`): `RenderResolutionTests` (1, from the game), `RenderResolutionScriptTests` (new, node:
  injection place + 9 pixelRatio cases incl. 895x393 @2.75 high 2.75 / low 2.75/3, iPhone/iPad auto low, ?dpr=native/2, short side, set/mode, follow).
- Framework docs: `CLAUDE.md` Modules (resolution, framerate), `releases/unreleased.md` step appended.
