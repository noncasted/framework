## Что сделано

- **GL (`Runtime/Collectors/GlCalls`)**. `TelemetryGlCalls.jslib` оборачивает методы `WebGL2RenderingContext.prototype` /
  `WebGLRenderingContext.prototype` один раз в `__postset` (при старте framework.js, до управляемого кода): Unity компилирует
  большую часть шейдеров при загрузке, обёртка на `GLctx` из конструктора скоупа их не видела (проверено сборкой: 0 компиляций).
  Считаются только вызовы `this === GLctx`; `this`, аргументы, результат и исключения те же. Пересозданный контекст покрыт
  прототипом. Время компиляции включает `getShaderParameter`/`getShaderInfoLog`, линковки — `getProgramParameter`/`getProgramInfoLog`
  (emscripten 3.x откладывает uniforms, Chromium/ANGLE ждут линковку в первом запросе статуса). Метка `webgl.shader.slow`
  detail `compile|compile status|link|link status`, `durationMs`, порог `ClientTelemetryOptions.slowShaderMs` (50), не больше 8 за
  сэмпл и 16 за сессию. Байты: `bufferData` (только с данными; число вызовов = перевыделения), `bufferSubData`, `texImage2D/3D`,
  `texSubImage2D/3D` (по размеру × формат/тип), `compressedTex*` (по размеру данных). Первый сэмпл сессии содержит всё с прошлого
  взятия (у первой сессии — загрузку Unity).
- `web.gl.errors_ms` — время цикла `getError` (jslib `TelemetryGlErrorsLastMs`).
- **Страница**: `page.fullscreen.enter/exit` (+ webkit-префикс), `page.resize` detail `css WxH buffer WxH` (ResizeObserver на canvas +
  `window.resize` для смены dpr, один отчёт через 500 мс, тот же размер — не отчёт, лимит 32 метки), `audio.context.<state>` через
  `addEventListener('statechange')` на `WEBAudio.audioContext` (Unity держит свой `onstatechange`, не трогается).
- **След**: `TelemetrySessionTrace` хранит последние 5 сэмплов 7 главных чисел (-1 = нет значения в JSON), уходит в
  `SessionStart.Previous`; сервер — `previous.samples [{time, hidden, values}]`; скилл печатает `previous_samples`.
- **Development** (`#if DEVELOPMENT_BUILD || UNITY_EDITOR`): `DevProfilerTelemetryCollector` — 9 счётчиков (`dev.gc.allocated_in_frame`,
  `dev.render.*`) и маркеры `devProfilerMarkers` → `dev.marker.<имя>` (среднее за кадр и `.max`, мс). Runtime-`if` не годится:
  генератор строит все регистрации.
- **Скилл**: 3 повтора (1, 2, 2 с) на таймаут/сброс, HTTP-коды не повторяются; детали меток в строке `marks`.
