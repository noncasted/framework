## Findings

- No MCP tools in a subagent of this job: the direct bridge (`ue.py`) works.
- Location decision (requirement 2): stress runs on the scene `Game` (D2BlueRedX2: trees, bushes, decor, water). Reasons:
  a new location through `LocationAssembler` needs a new `LocationLayout` with its own recipes and generated layers (the
  recreate-scene pipeline; the D2BlueRedX2 folder alone is 44 MB of generated art, a copy would need new guids and a 44 MB binary
  diff), and a `Stress.unity` with the existing location prefab in a stress scene group would make SharedAddressablesSync move the
  location's assets into `Shared_*` - the website / telegram bundles would change, against "byte for byte".
- A reference from a stress-only addressable group to any asset of a normal group changes the normal builds (SharedAddressablesSync);
  stress data must stay reference-free.
- `context_meter --marker` works in g2 (one file).
