### Burst (по запросу пользователя)
1. **Burst компилирует под WebGL в этой версии.** Unity 7000.0.0a10, `com.unity.burst` 2.0.0 встроен в редактор (shim
   package). В прошлой WebGL-сборке общего дерева есть `Library/Bee/artifacts/WebGL/AsyncPluginsFromLinker/lib_burst_generated.wasm`
   (124 КБ, статическая линковка `burst_enable_static_linkage = 1`). В `AsyncPluginsFromLinkerSymbols/lib_burst_generated.txt`
   флаги `--platform=Wasm --target=WASM32 --backend=burst-llvm-23 --opt-for-size --float-precision=Standard`, safety off.
   Методы там только из пакетов (UnsafeStream и т.п.), кода игры нет. `ProjectSettings/BurstAotSettings_WebGL.json`:
   `EnableBurstCompilation: true`, `OptimizeFor: 2`. То есть `[BurstCompile]`-функции на WebGL идут в wasm через Burst,
   а не через IL2CPP. Потоков нет: job выполняется на главном потоке.
2. **Замер Burst в WebGL-сборке не делался**: не хватило бюджета контекста. Нужен отдельный небольшой билд
   (`/home/nndd/.claude/jobs/9180826f/tmp/bench/build-local.sh` через flock) с драйвером, который гоняет горячий цикл
   (например, `Part` над `SwarmCrowd`) в двух вариантах: обычный C# (IL2CPP) и `[BurstCompile]`-статик над
   `NativeArray`/указателями. Ожидание [оценка]: против IL2CPP+clang выигрыш намного меньше «40× против Mono».
   Вероятно 1-3× на чистой арифметике, тем более wasm-SIMD здесь, похоже, не используется (в `UnityEditor.BurstModule`
   есть строка «WASM does not contain any SIMD instruction»), а `--opt-for-size` ещё ограничивает Burst.
   Барьер: код роя читает ECS StaticEcs (managed generic statics) и `EnemyKind` (классы), а в Burst так нельзя. Нужен
   перенос данных в плоские буферы, как уже сделано в `SwarmCrowd`.
3. **HPC#-стиль в IL2CPP**: перевод `Part` на плоские массивы (`SwarmCrowd`) и есть этот шаг. В редакторе movement
   ускорился в 4.2 раза. Отдельного IL2CPP-замера нет (это тот же WebGL-билд из п.2).

## Находки и решения
- `SwarmAttacks._random = new()` без сида (неприцельная стрельба). У тестовых видов прицел, поэтому md5 стабилен, но
  эталон с неприцельным видом был бы недетерминирован.
- `SwarmWorld.cs` (640 строк) и `SwarmView.cs` (635) больше лимита P11; в этом шаге не резались.
- Атрибут `[Il2CppSetOption]` объявлен только внутри StaticEcs (`internal`), игре недоступен. Чтобы снимать проверки
  границ, нужен свой файл атрибута в сборке игры.
